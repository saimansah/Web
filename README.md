# Saiman Sah — Portfolio

A responsive React, TypeScript, Tailwind CSS, Vite, and Three.js portfolio. The hero uses an original particle nebula and starfield inspired by the dark space aesthetic of [God’s Eye](https://www.godseye.world/home).

## Run locally

Requires Node.js 20.19+ or 22.12+.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. To type-check and build the production site:

```powershell
npm run typecheck
npm run build
npm run preview
```

## Certificates

All 18 supplied PDFs are stored in `public/assets/certificates/` and linked from the certificate cards. The round arrow opens a PDF in a new tab. Cards with multiple files open a short menu with an individual link for each PDF.

## Site files

- `index.html` contains the page metadata and structured data.
- `404.html` is the custom not-found page for static hosts that support custom 404 files.
- `public/robots.txt` and `public/sitemap.xml` help search engines discover the site.
- `public/assets/og-cover.png` is the social sharing image; its vector source is `public/assets/og-cover.svg`.

Certificate titles follow the supplied documents. The AWS item is labeled as an AWS SimuLearn: Cloud Practitioner completion certificate.
